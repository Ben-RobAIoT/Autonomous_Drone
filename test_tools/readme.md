Trong file control_motors.py. Để mà arm được bằng code thì làm như sau
1. Mở tay cầm lên để arm bằng tay cầm
2. Chuyển sang mode alt_hold (nút gạt phải vào vị trí giữa)
3. Thử arm bằng tay cầm trước
4. Nếu arm được thì qua code sẽ cd vào drone_controller và chạy python (python drone_controller.py)

Workspace này chủ yếu sẽ là các file test nhanh cảm biến, pin, motors,.... mà không cần vào mission planner chỉ cần chạy file nào muốn
